# MioDolce · Frontend

Next.js 16 (App Router) + React 19 + Tailwind CSS v4.

```bash
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000 (a API precisa estar rodando em http://localhost:5080)
```
